# 📊 Task 1: Student Performance Analysis

## 🎯 Objective
Analyze student data to understand factors affecting academic performance.

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📈 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Insight Generation

## 📊 Key Visualizations
- Study Time vs Marks
- Failures vs Marks
- Absences vs Performance
- Correlation Heatmap
- Average marks distributions 
- Lifestyle Factors Analysis

## 💡 Insights
1.Study time positively impacts student performance
2. Previous marks (G1, G2) strongly influence final marks (G3)
3. Students with failures tend to score lower
4. Higher absences lead to poor performance
5. Parental education has a noticeable impact
6. Lifestyle factors like going out and internet access affect performance
